## 1. How to use

1. **Order.** Work top to bottom inside each week of the pacing plan below. Discovery steps (finding the real group, reading its rules) come before any post in that group.
2. **Pacing.**
   - At most **2 community posts a day** across all platforms. A "post" is a new post or a long reply.
   - Threads/IG comments (section E) don't count toward that limit, but keep them to **5 a day**, and only on posts where they really help.
   - Never paste the same text in two groups in the same week. Edit at least the first two lines.
3. **Groups need approval.** Ask to join first, answer the entry questions honestly ("家人有請外籍看護／我在做雇主記帳的免費工具"), and wait. Read the pinned post / 社團規則 before the first post. If the rules ban links or self-promotion, post the **no-link version** and never add the link later.
4. **No links on PTT, ever.** Don't name the product on PTT unless someone asks directly. If asked, answer in one line and disclose: 「我是做這個工具的人」.
5. **Helpful first.**
   - Every post must be useful even if nobody clicks anything. Product mentions go **last**, are optional, and always disclose: 「（我是開發者）」.
   - Mention a non-app alternative too (notebook, shared Excel).
   - No made-up experiences. Anything in 【】 is a placeholder: replace it with something true or delete it.
6. **Compliance wording, in every piece.**
   - Spending is for the cared-for elder and the household, never for errands for other relatives.
   - 家用金 stays separate from salary and is never deducted from it.
   - For contract questions, point to the broker or 1955.
7. **Log it.** After each item goes live, write the date and post URL in the Status log (section 4).

```
   令尊72歲，不適用「80歲以上免巴氏量表」，需要到指定醫院做專業評估，

   長照3.0上路後，有聘外籍看護的家庭也可以使用日照／家托，
   不用因為請看護就停掉，可以跟照專確認。

4. 工作範圍
   家庭看護工是住在家裡、照顧被看護者為主，包括生活起居、陪同移動、陪診，
   但有休息與休假的權利（看契約），也不能叫她做照顧以外的工作（例如去別的親戚家幫忙）。
   「24小時」比較接近「24小時有人在身邊」，不是24小時不休息。

5. 媽媽不願意
   很多家庭的做法是先說「請一個人來幫忙扶爸爸、讓妳休息」，
```

### P4: PTT elderly, new post (category 老居, no link)
Title: `[老居] 請外籍看護後，買菜錢／家用金大家怎麼給？整理6種`
```
最近在整理請外籍看護的家庭怎麼處理「買菜、日用品的錢」，
發現每家做法差很多，也常是雇主和看護之間摩擦的來源，
整理成6種，想聽聽板上有經驗的大家是哪一種、有什麼眉角：

1. 固定週轉金
   每週先給一筆（例如2000），剩不到某個數字就補。
   對帳只要一句話：給的錢 = 花掉的 + 手上剩的。

2. 每次給整數、找零歸還
   大概400就給500，發票和零錢放在約定的位置。
   每趟都對得上，但紙條會越積越多。

3. 先墊後報
   看護先用自己的錢買，再拿收據報帳。
   不建議當常態，她的薪水多半要寄回家，等於借錢給雇主。

4. 雇主自己買、網購送到家
   看護只用一小筆錢補買青菜水果，手上現金少，帳好對。

5. 每月固定伙食費
   看護自己的三餐另外給一筆讓她自己安排（例如穆斯林看護）。
   重點是跟家用金分開，不然月底一定對不起來。

6. 店家記帳或儲值卡
   跟巷口雜貨店說好先記帳、雇主每週去結；或給儲值卡。

不管哪一種，大家講最多的幾個原則：
- 金額固定、交錢的時候雙方確認
- 收據留著（傳統市場沒收據就寫在本子上）
```
